# Intervall-Timer

Installierbare Web-App (PWA) für Intervalltraining mit Anspannen/Entspannen-Phasen, Atemübungen, Überraschungs-Programmen, Tageserinnerungen per Kalender und Trainingsverlauf.

- Läuft offline nach dem ersten Öffnen
- Verlauf und Plan bleiben nur auf dem Gerät (localStorage)
- Live: https://d-serafin.github.io/intervall-timer/
